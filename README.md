## How to Use

1. **Start with index.html** - Explore the foundational principles
2. **Navigate to flowchart.html** - See the complete pathway
3. **Choose your entry point:**
   - Work through Steps 1-7 sequentially (rigorous approach)
   - Jump to specific strategies as needed (practical approach)
4. **Copy prompts directly** - Use the "Copy Prompt" buttons for immediate use
5. **Return and refine** - This is a resource for ongoing use, not one-time consumption

## Hosting on GitHub Pages

To host this on your GitHub Pages:

### Option 1: As a subdirectory
1. Create a new repo or use existing
2. Upload the entire `differentiation-manual` folder
3. Enable GitHub Pages in repo settings
4. Site will be live at: `https://yourusername.github.io/repo-name/differentiation-manual/`

### Option 2: As root site
1. Create repo named `yourusername.github.io`
2. Upload the **contents** of differentiation-manual (not the folder itself) to root
3. Site will be at: `https://yourusername.github.io/`
